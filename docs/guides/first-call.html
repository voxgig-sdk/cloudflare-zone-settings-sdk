Make your first API call

  1. Choose an SDK from the SDK section and follow its installation instructions.
  2. Configure the API server and authentication settings.
  3. Open the CacheSettingsOriginH2MaxStreamsResponseValue reference and supply the parameters and request body it requires.
  4. Call list and inspect the returned entity data.

The first endpoint is GET /zones/{zone_id}/settings/origin_h2_max_streams. Request and response examples come from the API specification.
