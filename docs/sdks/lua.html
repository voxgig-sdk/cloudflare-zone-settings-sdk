Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

local sdk = require("cloudflare-zone-settings_sdk")
local client = sdk.new({apikey = os.getenv("CLOUDFLARE_ZONE_SETTINGS_APIKEY")})
