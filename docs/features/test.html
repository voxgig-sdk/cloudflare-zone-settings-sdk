Features

Test transport

In-memory mock transport for testing without a live server

A feature adds behaviour around API calls without changing how you call the API. Being documented here does not mean it is switched on: features are off by default, and you enable the ones your application needs when you construct the client.

Options

The settings this feature reads, with the defaults compiled into the SDK. Pass replacements in the client configuration to change them; set active to turn the feature on.

{
  "active": false
}

Pipeline stages

The points in the request lifecycle where this feature runs. The SDK calls each stage in order as it prepares a request, sends it, and handles the response.

  • GetMatch
  • PostConstruct
  • PostConstructEntity

  • PreRequest
